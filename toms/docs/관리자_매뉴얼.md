# 탐스 관리자 매뉴얼

이 문서 하나와 매일 아침의 **오늘의 브리핑**만 있으면 원장 없이 하루를 운영할 수 있습니다.

## 하루 순서

| 시간 | 할 일 |
|---|---|
| 13:30 출근 | 브리핑을 엽니다. **긴급**부터 위에서 아래로 처리합니다. |
| 14:00 | **오늘 등원** 명단을 봅니다. 이름 옆 표시(레벨업 대상, 책 고르기 도움, SR 진단…)가 오늘 그 아이에게 해 줄 일입니다. |
| 14:10 ~ | 도서관 운영. 등원 시간 10분이 지나도 안 온 학생은 바로 학부모에게 문자를 보냅니다. |
| 틈날 때 | **오늘 안에** 항목을 처리합니다. 문자 초안은 `복사` 버튼으로 가져가 그로우즈에서 보냅니다. 보내기 전에 한 번 읽습니다. |
| 마감 전 | 운영시트에 오늘 기록을 적고, 마감 체크리스트를 확인합니다. |

**이번 주** 항목은 한가한 날 몰아서 합니다. 다만 며칠째인지 옆에 표시되고, 기한을 넘기면 원장 주간 리포트에 `지연`으로 올라갑니다.

## 가장 중요한 규칙: 한 일은 반드시 적는다

브리핑의 할 일은 체크한다고 사라지지 않습니다. **운영시트에 기록해야 다음 날 사라집니다.**
체크박스는 오늘 하루 내가 어디까지 했는지 보는 용도입니다.

| 한 일 | 어디에 | 무엇을 |
|---|---|---|
| 결석 학부모에게 연락 | 상담연락 | 구분 `결석연락`, 방법 `문자` 또는 `전화` |
| 미납 안내 | 상담연락 | 구분 `수납연락` |
| 정기 상담 전화 | 상담연락 | 구분 `정기상담`, 내용 한 줄 |
| 신입 해피콜 | 상담연락 | 구분 `해피콜` |
| 레벨을 올리거나 내림 | 학생 + 상담연락 | 학생 시트의 `현재레벨` 수정, 상담연락에 구분 `레벨안내` |
| 축하 문자 | 상담연락 | 구분 `칭찬` |
| 보강 | 출결 | 보강 온 날 상태 `보강` |
| 청구서 발송 | 수납 | 청구월·금액·납부기한 한 줄 추가 |
| 입금 확인 | 수납 | 해당 줄의 `납부일` |
| SR 테스트 | 레벨진단 | 날짜·이름·점수 |
| 문의 응대 | 문의 | `상태`와 `최근연락일` 갱신 |
| 약속한 회신 | 상담연락 | 그 줄의 `후속완료`에 `Y` |

학부모에게 "확인해서 연락드리겠다"고 했다면, 그 줄의 `후속조치일`에 날짜를 적어 두세요. 그날 브리핑에 다시 뜹니다.

## 혼자 결정해도 되는 것

브리핑에 뜬 일은 원장이 미리 정한 기준에 따른 것이므로 **물어보지 않고 처리합니다.**

- 레벨업·레벨 조정 (브리핑에 뜬 수치 그대로)
- 결석·미납 안내 문자와 전화
- 보강 일정 잡기
- 정기 상담 전화, 신입 해피콜
- 신규 문의 회신, 진단 평가 예약과 진행
- 축하 문자, 명예의 전당 게시

## 원장에게 넘기는 것

브리핑 아래쪽 **원장에게 전달** 칸에 뜬 일은 직접 처리하지 않고 그대로 전달합니다.

- 결석 누적 (3회 연속, 또는 4주간 30% 이상)
- 독해 부진 지속 (레벨을 내려도 6권째 60% 미만)
- 장기 미납 (14일 경과)
- 이탈 위험 (여러 신호가 겹친 학생)
- 초4 입시반 전환 상담

브리핑에 없더라도 아래 경우는 바로 원장에게 알립니다.

- 학부모가 **퇴원·환불·불만**을 말했을 때
- 원비 할인, 시간표 예외처럼 **기준에 없는 요청**을 받았을 때
- 아이가 다치거나 아이들 사이에 **다툼**이 있었을 때

이때 학부모에게는 약속하지 않습니다. "원장님께 전달드리고 오늘 안에 다시 연락드리겠습니다"라고만 하고, 상담연락 시트에 구분 `클레임`으로 적습니다.

## 상담 전화 순서

1. 브리핑의 **통화 전 브리프**를 펼쳐 숫자를 봅니다 (출석, 읽은 권수, 정답률, 레벨).
2. 인사 → 숫자로 근황 → "집에서는 어떤가요?" → 요청 사항 듣기 → 다음 계획 한 가지.
3. 끊은 직후 상담연락 시트에 한 줄 적습니다. 길게 쓰지 않아도 됩니다: 누구 / 주제 / 결론 / 다음.

다른 학원이나 다른 아이와 비교하지 않습니다. 아이의 지난달과 이번 달을 비교합니다.

## 데이터 점검 칸

브리핑 아래 **데이터 점검**에 뜨는 것은 입력 실수입니다 (이름 오타, 날짜 형식, 빠진 출결).
그날 안에 고칩니다. 그대로 두면 다음 날 브리핑과 학부모 리포트가 틀리게 나옵니다.
