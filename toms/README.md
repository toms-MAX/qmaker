# 탐스 운영 OS

원장이 학원에 없어도 관리자 한 명으로 영어도서관이 돌아가게 하는 시스템입니다.

원리는 하나입니다. **원장의 판단을 규칙으로 적어 두고, 규칙이 매일 관리자의 할 일을 만들고, 관리자 권한 밖의 일만 원장에게 올라옵니다.**

```
 관리자가 입력              원장이 정한 기준             매일·매주 자동 생성
┌──────────────┐        ┌──────────────┐        ┌─────────────────────────┐
│ 운영시트.xlsx │  ───▶  │  rules.toml  │  ───▶  │ 오늘의 브리핑  (관리자)   │
│ 학생·출결·독서 │        │ 레벨업 기준,   │        │ 주간 리포트    (원장)     │
│ 수납·상담·문의 │        │ 결석·미납 단계 │        │ 월간 독서 리포트 (학부모) │
└──────────────┘        └──────────────┘        └─────────────────────────┘
```

## 원장이 빠져도 되는 이유

| 지금 원장 머릿속에 있는 것 | 시스템에서는 |
|---|---|
| "이 아이 레벨 올릴 때 됐나?" | 현재 레벨 책 8권 이상, 최근 5권 평균 85% 이상이면 브리핑에 `레벨업 2.6 → 2.9`와 학부모 축하 문자 초안이 뜹니다. |
| "누가 요즘 안 나오지?" | 사유 없는 결석은 당일 문자, 2회 연속은 관리자 전화, 3회 연속은 원장에게 넘어옵니다. |
| "이번 달 누가 안 냈지?" | 결제일 7일 전 청구, 3일 경과 문자, 7일 경과 전화, 14일 경과 시 원장에게 넘어옵니다. |
| "상담 전화 돌려야 하는데…" | 마지막 상담 후 60일이 지나면 명단에 오르고, 통화 전에 읽을 숫자 브리프가 함께 나옵니다. |
| "문의 온 거 회신했나?" | 문의 → 회신 → 진단 → 등록 단계마다 기한이 있고, 놓치면 `지연`으로 표시됩니다. |
| "관리자가 잘하고 있나?" | 주간 리포트에 관리자가 기한을 넘긴 일이 며칠째인지 그대로 나옵니다. 할 일은 데이터에서 매번 다시 계산하므로 숨길 수 없습니다. |

원장에게 올라오는 일은 다섯 가지뿐입니다: 결석 누적, 독해 부진 지속, 장기 미납, 이탈 위험, 초4 입시반 전환 상담.

## 먼저 데모로 보기

```bash
cd toms
python -m toms_ops demo
```

지어낸 학생 24명으로 `out/` 폴더에 세 화면이 만들어집니다. 브라우저로 열어 보세요.

## 실제로 쓰기

1. `templates/탐스_운영시트_템플릿.xlsx`를 복사해 `data/운영시트.xlsx`로 둡니다. (구글 드라이브에 올려 구글 시트로 써도 됩니다.)
2. 학생 시트를 채웁니다. 그로우즈에서 학생 명단을 엑셀로 내려받아 붙여 넣으면 됩니다.
3. 관리자는 매일 마감 전에 출결·독서기록·상담연락·문의를 적습니다. → [관리자 매뉴얼](docs/관리자_매뉴얼.md)
4. 아침마다 브리핑을 만듭니다.

```bash
python -m toms_ops brief      # 오늘의 브리핑 (관리자)
python -m toms_ops weekly     # 주간 리포트 (원장)
python -m toms_ops monthly    # 지난달 학부모 독서 리포트
python -m toms_ops check      # 입력 오류만 점검
```

`data/`와 `out/`은 git에 올라가지 않습니다. 학생 개인정보는 저장소에 넣지 않습니다.

## 매일 자동으로 돌리기 (Claude Code)

저장소에 Claude 스킬 네 개가 들어 있습니다. Claude Code에서 이름으로 부르면 됩니다.

| 스킬 | 하는 일 |
|---|---|
| `/toms-brief` | 드라이브의 운영시트를 받아 브리핑을 만들고 드라이브에 올립니다. |
| `/toms-weekly` | 주간 리포트를 만들고, 원장이 볼 핵심만 요약합니다. |
| `/toms-monthly` | 월간 독서 리포트를 만들고, 학생별 코멘트를 Claude가 다듬습니다. |
| `/toms-log` | "오늘 가온이 어머니랑 통화했어, 다음 주부터 나온대"처럼 말로 하면 운영시트에 넣을 줄로 바꿔 줍니다. |

Claude Code 웹의 예약 작업에 `/toms-brief`를 평일 오후 1시 반, `/toms-weekly`를 월요일 아침으로 걸어 두면 원장이 손대지 않아도 매일 브리핑이 드라이브에 쌓입니다.

## 기준 바꾸기

`config/rules.toml`의 숫자만 고치면 됩니다. 예를 들어 레벨업을 더 엄격하게 하려면:

```toml
[reading]
levelup_min_avg = 90        # 85 → 90
min_books_at_level = 10     # 8 → 10
```

학부모에게 가는 문자 문구는 `config/templates.toml`에 있습니다.
그로우즈·결제선생·AR에서 내려받은 파일의 열 이름이 다르면 `config/columns.toml`에 별칭을 적습니다.

## 일부러 하지 않은 것

- **문자를 자동으로 보내지 않습니다.** 초안까지만 만듭니다. 학부모에게 나가는 글은 사람이 한 번 읽고 보냅니다.
- **그로우즈·결제선생에 직접 연결하지 않습니다.** 두 서비스가 외부 연동(API)을 제공하는지 아직 확인하지 못해, 엑셀 내려받기와 붙여넣기를 전제로 했습니다.
- **입시반(초5 이상) 전용 규칙은 아직 없습니다.** 출결·수납·상담·문의 규칙은 입시반 학생에게도 적용되지만, 레벨 진급(80점)·오답 순환은 다음 단계입니다.

## 폴더

```
toms/
  config/      rules.toml(판단 기준) · templates.toml(문자) · columns.toml(열 별칭)
  docs/        관리자 매뉴얼
  templates/   빈 운영시트
  toms_ops/    store(읽기) · rules(규칙) · metrics(지표) · render(화면) · cli
  tests/       python -m unittest
```
