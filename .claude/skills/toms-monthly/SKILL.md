# 월간 독서 리포트

## 순서

1. 운영시트를 받는다 (`toms-brief` 스킬의 1번과 같다).
2. `cd toms && python -m toms_ops monthly --month YYYY-MM` (월을 안 주면 지난달).
   `out/월간리포트_YYYY-MM_재료.json`에 학생별 숫자와 기본 코멘트가 나온다.
3. 재료를 읽고 학생별 코멘트를 써서 `out/comments.json`에 `{"이름": "코멘트"}`로 저장한다.
4. `python -m toms_ops monthly --month YYYY-MM --comments out/comments.json`으로 다시 만든다.
5. `out/월간리포트_YYYY-MM.html`을 드라이브의 `탐스 브리핑` 폴더에 올리고, 관리자가 읽어 본 뒤 인쇄·발송하도록 안내한다.

## 코멘트 쓰는 법

- 3~4문장. 숫자 하나, 눈에 띈 변화 하나, 다음 달에 할 것 하나.
- 재료에 있는 사실만 쓴다. 수업 태도나 성격처럼 기록에 없는 것은 지어내지 않는다.
- 다른 아이와 비교하지 않는다. 그 아이의 지난달과 비교한다.
- 정답률이 낮은 달은 숨기지 않되, 다음 달 계획과 함께 쓴다.
- 탐스의 말투: 차분하고 따뜻하게. "~했습니다", "~하겠습니다". 느낌표와 과장된 칭찬은 쓰지 않는다.
- 학생 시트 메모에 있는 관심사(좋아하는 시리즈 등)가 있으면 한 번 언급한다.

코멘트는 초안이다. 보내기 전에 관리자가 반드시 읽는다는 점을 보고에 적는다.
