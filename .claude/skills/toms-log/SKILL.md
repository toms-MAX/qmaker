# 말로 기록하기

기록이 귀찮아서 빠지면 브리핑 전체가 틀어진다. 말한 것을 운영시트 형식으로 바꿔 준다.

## 순서

1. 말에서 누구, 언제(안 말하면 오늘), 무엇을 뽑는다.
2. 어느 시트인지 정한다.
   - 학부모와 연락함 → `상담연락` (날짜, 이름, 구분, 방법, 내용, 후속조치일, 후속완료, 담당)
   - 새 문의·문의 진행 → `문의` (문의일, 학생이름, 학년, 연락처, 경로, 상태, 진단일, 최근연락일, 메모)
   - 결석 사유·보강 → `출결`
   - 레벨 변경 → `학생`의 현재레벨 + `상담연락`에 구분 `레벨안내`
3. 구분은 반드시 다음 중 하나: 정기상담, 결석연락, 수납연락, 해피콜, 전환상담, 레벨안내, 칭찬, 클레임, 기타.
   무엇을 고르느냐에 따라 브리핑의 할 일이 사라지므로, 애매하면 물어본다.
4. "확인해서 연락드린다"는 약속이 있으면 후속조치일을 채운다.
5. 이름이 학생 시트에 있는지 확인한다 (`python -m toms_ops check`). 비슷한 이름이 여럿이면 물어본다.
6. 구글 시트에 직접 쓸 수 있으면 해당 시트 맨 아래에 추가하고, 없으면 붙여 넣을 수 있게 탭으로 구분한 한 줄을 보여 준다.

## 지킬 것

- 말하지 않은 내용을 채워 넣지 않는다. 내용 칸은 들은 대로 한두 문장으로 줄인다.
- 퇴원·환불·불만이 언급되면 구분을 `클레임`으로 하고, 원장에게 알려야 한다고 덧붙인다.
