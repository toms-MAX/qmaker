# 주간 리포트

원장이 학원에 없어도 일주일에 한 번, 5분 안에 학원 상태를 판단할 수 있게 한다.

## 순서

1. 운영시트를 받는다 (`toms-brief` 스킬의 1번과 같다).
2. `cd toms && python -m toms_ops weekly`
3. `toms/out/주간리포트_<날짜>.html`을 드라이브의 `탐스 브리핑` 폴더에 올린다.
4. `python -m toms_ops tasks`의 JSON을 읽고 원장에게 다음 순서로 보고한다.
   - **직접 할 일**: `assignee`가 원장인 건. 학생별로 무엇을, 왜.
   - **관리자 지연**: `overdue`가 true인 관리자 건. 같은 분류가 2주 연속 지연이면 그 점을 짚는다.
   - **숫자의 변화**: 지난주보다 눈에 띄게 달라진 지표 한두 개와, 데이터에서 보이는 이유.
   - **규칙 제안**: 같은 유형의 원장 건이 반복되면, 관리자에게 넘길 수 있도록 `rules.toml` 기준을 어떻게 바꿀지 제안한다. 직접 고치지는 않는다.

## 지킬 것

- 지표를 좋게 보이도록 다듬지 않는다. 기록이 없어서 계산하지 못한 값은 "기록 없음"이라고 쓴다.
- 원인을 추측할 때는 추측이라고 밝힌다.
